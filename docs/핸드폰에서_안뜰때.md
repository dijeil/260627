# 핸드폰에서 대시보드가 안 뜰 때

> 집에서는 잘 됐는데 회사 컴퓨터로 옮기니 폰에서 안 보일 때 읽는 문서입니다.

## 가장 흔한 원인: 컴퓨터가 바뀌면 주소도 바뀝니다

파일은 옮길 수 있지만 **주소는 따라오지 않습니다.**

| | 집 컴퓨터 | 회사 컴퓨터 |
|---|---|---|
| 주소 | `http://100.107.118.70:8100` | **완전히 다른 주소** |
| 폰 즐겨찾기 | 집 주소가 저장돼 있음 | 이 주소로는 영영 안 열림 |

폰이 계속 **집 컴퓨터 주소**를 찾아가고 있어서 `ERR_CONNECTION_TIMED_OUT` 이 뜨는 겁니다.
집 컴퓨터는 지금 회사에 없으니 응답할 수가 없습니다.

### 해결

회사 컴퓨터에서 대시보드를 켜 둔 채로 아래를 실행하세요.
**지금 이 컴퓨터가 어디인지**와 **지금 써야 할 주소**를 알려줍니다.

```
python tools/mobile_check.py 8100
```

실행하면 이렇게 나옵니다.

```
================================================================
  ■ 지금 이 컴퓨터 : 회사 컴퓨터   (이름: DESKTOP-ABC)
================================================================

  [다른 컴퓨터에 저장된 주소] — 지금은 이 주소로 들어가면 안 됩니다
    · 집 컴퓨터 (집-PC) : http://100.107.118.70:8100

[2] 폰 브라우저에 넣을 주소  (회사 컴퓨터 기준)
 [OK] 같은 와이파이용 (가장 간단, 권장):
       http://192.168.0.37:8100      ← 폰에 이 주소를 넣으세요
```

처음 한 번만 "이 컴퓨터는 집인가요 회사인가요?" 하고 물어봅니다.
한 번 답하면 `hosts.json` 에 저장돼서 다시 묻지 않습니다.

- 이름표를 바꾸고 싶으면: `python tools/mobile_check.py --rename`

## 대시보드 화면에도 표시하기

대시보드 상단에 "지금 집/회사 어느 컴퓨터인지 + 주소"를 띄우면 헷갈릴 일이 없습니다.
**한 줄만 추가하면 됩니다.**

```python
from utils.host_label import banner

# Streamlit
st.caption(banner(8100))

# Flask / FastAPI / 일반 파이썬
print(banner(8100))
```

출력 예시:

```
회사 컴퓨터 (DESKTOP-ABC) · http://192.168.0.37:8100
```

## 주소 종류 한눈에

| 주소 모양 | 뜻 | 폰에서 되나요 |
|---|---|---|
| `http://localhost:8100` | 이 PC 전용 | ❌ 절대 안 됨 |
| `http://127.0.0.1:8100` | 이 PC 전용 | ❌ 절대 안 됨 |
| `http://192.168.x.x:8100` | 같은 와이파이 | ✅ **가장 쉬움 (권장)** |
| `http://100.x.x.x:8100` | Tailscale(VPN) | ⚠️ 양쪽 다 Tailscale 켜야 함 |

`100.107.118.70` 은 **Tailscale 전용 주소**입니다.
회사 컴퓨터에 Tailscale이 깔려 있지 않거나 꺼져 있으면 그 주소는 쓸 수 없습니다.

> 제일 편한 방법: 폰과 회사 PC를 **같은 와이파이**에 두고 `192.168.x.x` 주소를 쓰세요.

## 에러 메시지별 원인

### `ERR_CONNECTION_TIMED_OUT` (응답이 아예 없음)
폰이 PC까지 못 가고 있습니다.

1. **옛날(집) 주소로 접속 중** ← 이번 경우가 여기입니다
2. 폰 Tailscale이 꺼짐 (100.x.x.x 주소를 쓸 때)
3. 폰이 와이파이가 아니라 **LTE/5G**
4. **PC가 절전 모드**
5. 회사 **방화벽/보안 정책**이 포트를 막음

### `ERR_CONNECTION_ABORTED` (붙었다가 끊김)
PC까지는 갔는데 서버가 거절했습니다.

- 서버가 `127.0.0.1`에만 떠 있을 때 → 아래 "0.0.0.0으로 실행"
- 대시보드를 껐다 켜는 중에도 납니다.

---

## 0.0.0.0 으로 실행하기

그냥 띄우면 **그 PC에서만** 보입니다. 폰에서 보려면 `0.0.0.0`으로 열어야 합니다.

```bash
# Streamlit
streamlit run app.py --server.address 0.0.0.0 --server.port 8100

# FastAPI / uvicorn
uvicorn main:app --host 0.0.0.0 --port 8100

# Flask
app.run(host="0.0.0.0", port=8100)

# Dash
app.run(host="0.0.0.0", port=8100)
```

## 회사 방화벽이 막을 때

**관리자 권한** 명령 프롬프트에서:

```
netsh advfirewall firewall add rule name="Dashboard 8100" dir=in action=allow protocol=TCP localport=8100
```

회사 PC는 관리자 권한이 없거나 보안 정책으로 막혀 있을 수 있습니다.
그럴 땐 **폰 핫스팟**을 켜고 회사 PC를 거기에 연결한 뒤,
`python tools/mobile_check.py 8100` 을 다시 돌려 새 주소를 확인하세요.
회사 네트워크를 우회하므로 거의 항상 됩니다.
