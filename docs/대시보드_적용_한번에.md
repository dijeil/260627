# 대시보드에 한 번에 적용하기

이번에 만든 파일들은 **기존 대시보드 코드를 고치지 않고** `<script>` 줄만 넣으면 동작합니다.
`static/` 폴더의 파일을 대시보드의 `static/` 폴더에 복사한 뒤, 대시보드 HTML에 아래 줄을 넣으세요.

```html
<head>
  ...
  <!-- ① 가장 먼저: 화면의 모든 [CSV] 버튼 → 엑셀 더블클릭 시 한글 정상, 종목코드 0 보존 -->
  <script src="/static/excel_csv_fix.js"></script>
</head>
<body>
  ...
  <!-- ② 파산확률 공용 계산기 (3-5, 3-8, 3-9 가 같이 쓰기) -->
  <script src="/static/ruin_calc.js"></script>
  <!-- ③ 화면마다 [❓ 이게 뭐예요?] 버튼 + 칸 이름 설명 풍선 -->
  <script src="/static/dashboard_help.js"></script>
</body>
```

| 파일 | 하는 일 | 확인한 것 |
|---|---|---|
| `excel_csv_fix.js` | CSV 다운로드에 BOM 자동 추가, `005930` 보호 | 다운로드 방식 3가지 모두 + LibreOffice로 열어 한글·`005930` 정상 |
| `ruin_calc.js` | 파산확률을 **조건 문장과 함께** 계산 | 파이썬 `utils/ruin.py`와 같은 값, 3-9 화면값(0.005%)과 일치 |
| `dashboard_help.js` | 3-4~3-10 도움말 버튼, 용어 풍선 | 모형 화면(PC·휴대폰 폭)에서 버튼·풍선·화면 갱신 후 재부착 확인 |
| `chart_check.js` | 캔들차트 십자선 어긋남 원인 진단 | zoom·transform·크기 불일치 재현 페이지에서 정확히 찾음 |
| `chart_hts_kit.js` | HTS형 캔들차트(범례·자석·동기화·키보드) | 모형 라이브러리로 4.x·5.x 둘 다 동작 확인 |

### 3-9 화면을 공용 계산기로 바꾸는 예
```js
// 슬라이더가 움직일 때
const r = Ruin.report({ p: 승률/100, b: 손익비, N: 자본단위, source: "슬라이더" });
값칸.textContent  = r.headline;     // 0.005%
조건칸.textContent = r.condition;   // [슬라이더] 승률 55.0% · 손익비 1.50 · 1회 손실 = 자본의 5.0%(자본 20칸) · 끝없이 계속할 때
판정칸.textContent = r.verdict;     // 기대값 +0.375칸(플러스). 끝없이 해도 파산할 확률은 0.005%입니다.
```
3-5·3-8에서는 `T: 거래수`를 넣으면 "430번 매매하는 동안"의 값이 나옵니다.

### 도움말 문구 바꾸기
`dashboard_help.js` 맨 위의 `PANELS`(화면 설명)와 `TERMS`(칸 이름 설명)에 한 줄씩 추가·수정하면 됩니다.
칸 이름은 화면 글자와 **정확히 같아야** 풍선이 붙습니다(예: `"파산확률"`).
