## 1. 파산확률이 "다 틀려 보이는" 이유

| 화면 | 표시 | 실제로 계산한 것 |
|---|---|---|
| 3-5, 3-8 | **53.3%** | **실제 성적**(승률 36%, 손익비 1.724)으로 **정해진 횟수만큼** 매매할 때 (재계산해 보니 **자본 20칸, 430번 매매**일 때 55.5%로 거의 같음) |
| 3-9 | **0.005%** | **가상의 좋은 전략**(승률 55%, 손익비 1.5)을 **끝없이** 매매할 때 |

**계산식 자체는 둘 다 맞습니다.** 3-9 공식값은 직접 다시 계산해도 0.00501%(약 19,952번에 한 번)로 화면과 같습니다.
틀린 것은 **보여 주는 방식**입니다.
1. **같은 이름, 다른 조건.** 둘 다 "파산확률"이라고만 적혀 있고, 무슨 조건인지는 안 적혀 있습니다.
2. **3-9 슬라이더 기본값이 내 실제 성적이 아닙니다.** 55%·1.5는 가상의 좋은 전략입니다. 실제 성적(36%·1.724)을 넣으면 3-9 공식값은 **100%**가 됩니다. 기대값이 마이너스라 끝없이 하면 반드시 파산하기 때문입니다.
3. **3-9의 "옛 대칭 근사 0.00054%"는 다시 계산해도 나오지 않습니다.** 흔히 쓰는 근사식 두 가지로 계산하면 1.8%와 0.000014%가 나옵니다. 어느 식으로 계산했는지 원본 코드 확인이 필요합니다.

### 고친 방법: 모든 화면이 계산기 하나만 쓰게
- 파이썬: `utils/ruin.py`의 `ruin_report(p, b, N, T)`
- 화면(브라우저): `static/ruin_calc.js`의 `Ruin.report({p, b, N, T})`

두 계산기는 같은 값을 내도록 맞췄고 테스트로 확인했습니다. 값과 함께 **조건 문장**을 꼭 같이 보여 주세요.
```
55.5%
[실제 매매] 승률 36.0% · 손익비 1.72 · 1회 손실 = 자본의 5.0%(자본 20칸) · 430번 매매하는 동안
한 번 매매의 기대값이 -0.019칸(마이너스)이라 계속하면 언젠가 반드시 파산합니다.
본전 승률 36.7% 또는 본전 손익비 1.78 이상이 필요합니다.
```
3-9 슬라이더의 **처음 값은 3-5의 실제 승률·손익비로** 시작하도록 바꾸길 권합니다.

### 1회 손실 크기가 파산확률을 크게 바꿉니다 (실제 성적, 430번 매매 기준)

| 1회 손실 = 자본의 | 10% (10칸) | **5% (20칸)** | 3.3% (30칸) | 2% (50칸) |
|---|---|---|---|---|
| 파산확률 | 77.8% | **55.5%** | 35.8% | 10.5% |

**한 번에 거는 금액을 줄이는 것이 파산확률을 낮추는 가장 확실한 방법입니다.**

## 2. 3-9 켈리·파산 시뮬레이터 읽는 법

**슬라이더를 움직여 "이런 성적이면 얼마나 걸어야 하고, 망할 확률은 얼마인가"를 바로 보는 계산기입니다.**

| 항목 | 뜻 |
|---|---|
| 승률 p | 100번 중 몇 번 이기나 |
| 손익비 b | 이길 때 버는 돈 ÷ 질 때 잃는 돈 |
| 자본단위 N | 계좌를 몇 칸으로 나눠, 한 번 질 때 1칸을 잃는가. N=20이면 **한 번 질 때 자본의 5%** 손실 |
| 켈리 f* 25% | 수학적으로 돈이 가장 빨리 불어나는 베팅 비율. 실제로는 너무 공격적이라 **절반(하프켈리 12.5%)**을 권장 |
| 파산확률(공식) | 끝없이 매매할 때 계좌가 0이 될 확률 |
| 파산확률(몬테카를로) | 실제로 2,000번 가상 매매를 돌려 0이 된 횟수. 공식값이 너무 작으면 0회가 정상이고, 화면의 "모순 없음"은 공식과 시뮬레이션이 서로 맞는다는 뜻 |

> 켈리가 **0% 이하**로 나오면 = 기대값이 마이너스 = **"이 전략은 걸면 안 된다"**는 뜻입니다.
> 지금 실제 성적(36%, 1.724)으로 계산하면 켈리는 **−1.1%**입니다.

### 오른쪽 위: 검증 정확도 vs 다수클래스 기준선 (가장 중요)

|---|---|---|

**3초 판정: 초록 막대가 회색보다 길어야 AI가 뭔가를 배운 것입니다. 지금은 더 짧으므로 "찍기보다 못함"입니다.**

> ⚠️ **확인이 필요한 점:** 48.26% + 51.74% = **정확히 100%**입니다(344개 중 166개 대 178개).

### 아래: Epoch 손실곡선
| 용어 | 뜻 |
|---|---|
| epoch (가로축) | 공부 자료 전체를 처음부터 끝까지 **한 번 훑은 횟수** (1~10번) |
| 손실 loss (세로축) | **얼마나 틀렸나.** 낮을수록 좋음 |
| 0.693 | 오를지 내릴지 **동전 던지기로 찍을 때의 손실값** |

**읽는 법:** 10번 공부하는 동안 0.693 → 0.665로 **아주 조금만** 내려갔습니다. 동전 던지기에서 거의 벗어나지 못했다는 뜻입니다.
선이 내려가는 것은 "공부 자료에 익숙해졌다"는 뜻일 뿐이고, 진짜 실력은 위의 **시험 성적(48.26%)**으로 봐야 합니다.
